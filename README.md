# Домашний бюджет

Нативное Android-приложение на Java. Русский интерфейс, рубли, Android 8.0 и новее.

## Возможности

- Добавление расходов: сумма до копейки, категория, дата, комментарий.
- Редактирование записей и удаление с подтверждением.
- Восемь начальных категорий и добавление собственных.
- Общий лимит расходов отдельно для каждого месяца.
- Сводка расходов, остаток или превышение лимита, доли категорий.
- История по месяцам с фильтром по категории.
- Экспорт выбранного списка в CSV через системный выбор файла.
- Локальное сохранение без регистрации и разрешения на доступ к интернету.

При первом запуске история пустая. Демонстрационные операции не добавляются.
Денежные значения хранятся в целых копейках. Изменения проверяют результат записи на диск.

## Сборка на компьютере

Нужны JDK 17, Android SDK Platform 35 и Build Tools 34.0.0.
Gradle 8.9 загружается включённым в проект Wrapper. Android Studio и эмулятор для сборки APK не требуются.
Совместимость AGP 8.7 с Gradle 8.9 и JDK 17 описана в [документации Android](https://developer.android.com/build/releases/agp-8-7-0-release-notes).

Для Linux Ubuntu/Debian x86_64 выполните `bash .codex/setup.sh`.
Скрипт устанавливает консольные инструменты, принимает лицензии SDK и собирает APK.
Требуется root или sudo без пароля. Подробности: [CODEX-ENVIRONMENT.md](CODEX-ENVIRONMENT.md).

После настройки JAVA_HOME и ANDROID_HOME:

```sh
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
В Windows используйте `gradlew.bat assembleDebug`.

## Получение APK через GitHub

В проект добавлен `.github/workflows/android.yml`. Если загрузить содержимое папки
HomeBudget в корень своего репозитория, можно запустить workflow **Build Android APK**
во вкладке Actions. После успешной сборки скачайте артефакт **HomeBudget-APK**.
Это отладочный APK для установки и проверки; для публикации нужна релизная подпись.
Репозиторий не создавался и workflow в этой сессии не запускался.

## Проверка на устройстве

1. Добавьте 100,50 ₽ в «Продукты» и 50 ₽ в «Транспорт»: итог должен быть 150,50 ₽.
2. Установите лимит 200 ₽: остаток 49,50 ₽. Измените лимит на 100 ₽: превышение 50,50 ₽.
3. Измените первый расход на 80 ₽: итог 130 ₽.
4. Проверьте фильтр «Транспорт»: одна запись на 50 ₽.
5. Перенесите запись в другой месяц и проверьте обе месячные сводки.
6. Перезапустите приложение: записи, категории и лимиты должны сохраниться.
7. Проверьте отказ для нуля в расходах, отрицательной суммы и более двух десятичных знаков.
8. Добавьте категорию, затем расход с ней. Проверьте её в сводке и фильтре.
9. Экспортируйте CSV и откройте его: кириллица, даты и суммы должны совпадать.
10. Удалите расход: проверьте пересчёт. Проверьте интерфейс с крупным шрифтом и поворотом экрана.

## Статус и ограничения

Структура файлов и XML проверены. Сборка, Android Lint и проверки на устройстве
не выполнены: в окружении создания отсутствуют JDK, Gradle и Android SDK.

Данные хранятся в приватном хранилище приложения; удаление приложения удалит историю.
CSV предназначен для просмотра и внешней обработки; обратный импорт не реализован.
Лимит задаётся на месяц целиком, отдельные лимиты категорий не предусмотрены.
Нет синхронизации, банковских интеграций, доходов и повторяющихся платежей.
При повороте сохраняются месяц и вкладка; незавершённую форму расхода нужно заполнить заново.
